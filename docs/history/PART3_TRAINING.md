## Награда v4 («как у аккуратного человека»)
Старые члены (прогресс, полоса, курс, анти-дрожание руля `steer_rate` 1.5, `delta_rate`, педали, комфорт) не тронуты.

| что | как наказывается / поощряется |
|---|---|
| красный / жёлтый / «стоп» / «уступи» / зебра | разово −40 / −6 / −20 / −15 / −35 |
| превышение скорости, встречная половина | за шаг, мало (−0.05·min(Δv,5)², −0.03) |
| AEB (почти-авария) | −6 при срабатывании + −0.6 за шаг |
| столкновение | −50 × (стена 1.0, припаркованная 1.1, машина 1.4, автобус 1.5, **пешеход 3.0**) × скорость удара (0.7…1.15) |
| TTC до лидера, прогноз контакта по моей траектории, жёсткое торможение (не AEB) | малые штрафы, растут при сближении |
| дистанция до лидера **в секундах** | < 1.2 с — штраф (вес 3), 1.2…3 с за движущимся лидером — бонус |
| медленно / торможение **без причины** | штраф, только если нет `justified_stop`, лидера ближе 25 м, светофора/знака ближе 40 м |
| красный, пешеход, автобус на остановке, заблокированная полоса | **не штрафуются** |
| объезд припаркованной с частичным выездом на встречную | почти бесплатно; `proximity` теперь только < 1.2 м (был 6 м — отсюда страх объектов сбоку) |

## Эксперт v2 (учитель для BC)
Что изменено: короткий интерполированный look-ahead + выход наружу в крутых поворотах (раньше срезал угол и цеплял
стену); дистанция до лидера по времени (1.1 с); объезд припаркованной по плану от расстояния, с ожиданием свободной
встречной полосы и «сдать назад, если слишком близко»; пешеходы, которые окажутся в коридоре к моему приезду;
не вставать на зебре; не стоять вплотную к пешеходам; разворот в три приёма.

Измерено здесь (синтетический город, трафик, сложность 1.0, 80 эпизодов, одинаковые сиды):
| | успех | нарушения правил |
|---|---|---|
| эксперт из части 2 | 69 % (на сидах с recovery-стартами 52 %) | 0 |
| эксперт v2, без recovery-стартов | **94 %** (остаток: 2 стены, 2 пешехода, 1 тайм-аут) | 0 |
| эксперт v2, стандартный микс стартов (сиды 1000–1079 — те же, где часть 2 дала 52 %) | **85 %** (5 из 5 стартов «лицом назад» не вышли) | 0 |

**Слабое место, не решено:** старты «лицом назад / боком» (recovery). Эксперт выбирается из них примерно в 3 случаях
из 14 (раньше 0 из 5). BC такие эпизоды отбрасывает (в демонстрации идут только успешные), этому сеть должна научиться
сама в PPO.

Сделанное исключение из «не трогать работающее»: пешеходы мира идут сквозь *стоящую* машину, и агент получал «столкновение
с пешеходом», просто ожидая. Теперь контакт при |v| < 0.3 м/с не считается аварией агента (`ped_contact_speed`); как только
машина едет — считается. Файл мира `env/world.py` не менялся.

## Обучение
`python -m astana_pilot.training.train --run-name night1 --hours 8`
1. Демонстрации эксперта (300 эпизодов, 4 города, 40 % эпизодов с OU-шумом, метки — чистые действия эксперта) → BC политики
   (MSE, 15 эпох) → прогрев критика на дисконтированных возвратах с **тем же масштабом наград, что у VecNormalize**
   (иначе случайный критик ломает клонированную политику в первых апдейтах) → 1 раунд DAgger (ведёт ученик, размечает эксперт).
2. PPO: `n_envs` городов параллельно (каждому воркеру свой город из `--maps`), сеть `CityExtractor` (круговая Conv1d по
   лучам + MLP по остальному → 384 признака) + головы [256,256] на GPU (на CPU 192 + [128,128]), batch 4096 (подгоняется к
   `n_envs·1024`), gSDE с `log_std_init=-2`, для старта из BC: lr 1e-4, clip 0.15, target_kl 0.02, затем линейно до 10 %.
3. Куррикулум адаптивный: сложность +0.1 при успехе ≥ 80 %, −0.05 при < 45 %, страховка — к 8M шагов обязательно 1.0.
4. Автосохранение каждые 15 мин (`checkpoints/latest.zip` + `vecnormalize_latest.pkl`, запись через временный файл),
   нумерованные каждый 1M. Тот же командой запуск после обрыва **продолжает**. `--timesteps` — целевой итог, а не добавка.

TensorBoard (`tensorboard --logdir runs`), группа `custom/`: `success`, `collision_rate`, `collision/{wall,parked,car,bus,pedestrian}`,
`stall/lost/timeout`, `viol/{red_light,yellow_light,stop_sign,yield,zebra}`, `viol_any`, `aeb_frac`, `unneeded_slow_frac`,
`speeding_frac`, `wrong_side_frac`, `speed_kmh`, `steer_jerk`, `lane_dev_m`, `difficulty`, `rew/<часть награды>`.

## Оценка и заучивание карты
`python -m astana_pilot.training.evaluate --model runs/night1/final_model.zip --episodes 60`
Одни и те же сиды для модели и эксперта; «seen» = города обучения (`synthetic:0..3`), «unseen» = `synthetic:100..103`
(другие размеры/расстояния кварталов, другой расклад трафика и припаркованных). Таблицы: исход с интервалом Вильсона,
кто во что врезался, нарушения по видам, AEB, лишняя медлительность, скорость, дрожание руля, и проверка seen→unseen.
Наблюдение не содержит абсолютных координат, но проверка именно для этого и нужна.
Ограничение: unseen-города — тот же шаблон (сетка + кольцо + эстакада/тоннель). Настоящая карта Астаны — часть 4.
