# OpenStreetMap cache

The `*.json` files are cached answers of the Overpass API for the districts used by the presets (`astana map --preset expo|nurzhol`).
They make map building reproducible and offline.

If you publish maps or results derived from this data, keep this attribution. Delete the files to force a fresh download.
